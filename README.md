# ⚡ VPS Control Panel

A cyberpunk-themed web-based VPS management panel built with Node.js.

## Features
- Real-time system monitoring
- Web-based terminal
- PM2/Docker/Nginx management
- File manager with upload
- Firewall & Security center
- Backup system & User management
- Mobile responsive

## Install
git clone https://github.com/YOUR_USERNAME/vps-control-panel.git
cd vps-control-panel
npm install

## Run
npm start
Open http://YOUR_IP:3010 | Login: admin/admin
